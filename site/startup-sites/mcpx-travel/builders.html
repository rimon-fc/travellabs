/ Connect

Connect the way your agent works

Same tools, same results, three ways in. Pick the one that fits your stack.

MCP SERVER

For any MCP-ready assistant or agent framework. Add one server and the travel tools appear.

// mcp config
{
  "mcpServers": {
    "mcpx": {
      "url": "https://mcp.mcpx.travel",
      "headers": { "x-api-key": "$MCPX_KEY" }
    }
  }
}
REST API

Typed JSON over HTTPS. Send what the traveller asked for in plain words and get ranked options back.

# search in plain words
curl https://api.mcpx.travel/v1/search \
  -H "x-api-key: $MCPX_KEY" \
  -d '{"ask": "warm, July,
       4 people, under $3k"}'
CLI

For coding agents, scripts and quick tests from the terminal.

# search, hold, commit
$ npx mcpx login
$ mcpx search "SYD to NAN, 4-14 Jul"
$ mcpx hold off_7Q2K
$ mcpx commit hld_91F
